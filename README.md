## 🎶 About TuneFlow

TuneFlow is a modern web-based music player featuring a premium dark-neon interface, smooth interactions, responsive design, and an immersive listening experience.

### ✨ Features

* 🎵 Music Library
* ▶️ Audio Controls
* 🔎 Search
* ❤️ Favorites
* 🔀 Shuffle
* 🔁 Repeat
* 🎤 Artists
* 💿 Albums
* 🎼 Genres
* 📱 Fully Responsive UI
* 🌌 Premium Dark Theme
